# Internal Security Audit & Compliance Assessment

This repository contains a practical internal security audit case study focused on evaluating an organization’s security posture, existing controls, risk exposure, and compliance practices.

The material includes audit scope definition, risk assessment, security control categories, controls assessment, compliance review, and remediation recommendations.

## Audit Scope

The audit scope covers the organization’s overall security program, including:

- Organizational assets
- Internal processes and procedures
- Security controls
- Data protection practices
- Compliance requirements
- Business continuity considerations

The objective is to assess current controls and identify areas where additional security measures or compliance improvements are required.

## Risk Assessment

The assessment identifies weaknesses related to:

- Asset management
- Access control
- Data protection
- Security monitoring
- Backup and disaster recovery
- Password management
- Legacy system maintenance
- Compliance readiness

The case study highlights a relatively high level of risk due to gaps in control implementation and compliance practices.

## Security Control Categories

The controls are grouped into three main categories:

### Administrative / Managerial Controls

Examples include:

- Least privilege
- Disaster recovery planning
- Password policies
- Access control policies
- Account management
- Separation of duties

### Technical Controls

Examples include:

- Firewall
- Intrusion Detection / Prevention Systems
- Encryption
- Backups
- Password management systems
- Antivirus
- Legacy system monitoring and maintenance

### Physical / Operational Controls

Examples include:

- Physical locks
- CCTV surveillance
- Locking cabinets
- Fire detection and prevention systems
- Security signage
- Controlled physical access

## Control Types

The audit considers four major control types:

- Preventive
- Detective
- Corrective
- Deterrent

These controls work together to provide layered protection and support defense-in-depth.

## Key Findings

The audit identifies several important security gaps, including:

- Excessive access to sensitive information
- Lack of least privilege
- Lack of separation of duties
- Missing encryption
- No intrusion detection system
- No formal disaster recovery plan
- Lack of critical data backups
- Weak password controls
- No centralized password management
- Inconsistent legacy system maintenance

Existing controls include:

- Firewall protection
- Antivirus software
- Physical locks
- CCTV surveillance
- Fire detection and prevention systems

## Recommendations

Recommended improvements include:

1. Implement least privilege
2. Enforce separation of duties
3. Deploy an intrusion detection system
4. Encrypt sensitive information
5. Establish backup and disaster recovery procedures
6. Strengthen password policies
7. Introduce centralized password management
8. Formalize legacy system monitoring
9. Improve asset classification and inventory management
10. Limit access to sensitive and payment-related data
